# MusicXML 4.0 schema fixture

`musicxml.xsd`, `xml.xsd` and `xlink.xsd` are the MusicXML 4.0 XSD files used for local validation. Their copyright and specification notices are preserved in the files. The two imports in `musicxml.xsd` point to the adjacent copies so CI validates without fetching schemas from the network.

The CI fixture is generated by `scripts/omr-xml-fixture.ts` and validated with `lxml`. These files are test resources; the app does not bundle them.
