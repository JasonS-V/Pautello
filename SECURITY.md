# Política de Seguridad

En **Pautello** nos tomamos en serio la seguridad y estabilidad de nuestra aplicación y de los datos de nuestros usuarios.

---

## Versiones Soportadas

Actualmente se proporcionan parches de seguridad para las siguientes versiones:

| Versión | Soportada             |
| :------ | :-------------------- |
| `1.x`   | :white_check_mark: Sí |
| `< 1.0` | :x: No                |

---

## Reportar una Vulnerabilidad

Si descubres una vulnerabilidad de seguridad en este proyecto:

1. **No abras una issue pública** en GitHub.
2. Envía un correo electrónico directamente al mantenedor del proyecto: [jasonsting70@gmail.com](mailto:jasonsting70@gmail.com).
3. Incluye una descripción detallada del problema, los pasos para reproducirlo y, si es posible, una prueba de concepto (PoC).
4. El equipo revisará el reporte y responderá dentro de un plazo de 48 a 72 horas.
5. Una vez verificada y resuelta la vulnerabilidad, se publicará una nueva versión con el parche y se te dará el crédito correspondiente (si así lo deseas).
